# INRISHI Main V71 Production Release

Frontend `71.0.0` for `https://www.inrishi.in`.

This release requires the shared Apps Script backend contract `63.0.0` at the existing production `/exec` URL. GitHub Actions verifies backend health before installing dependencies or deploying Pages.

V71 is a product-positioning rebuild: simplified AI-software positioning, product UI simulations, public pricing, enterprise/AI transformation sections, stronger navigation and legal footer pages. Existing Admin/Customer authentication and portal architecture are preserved.
