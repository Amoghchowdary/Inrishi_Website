INRISHI V39 PRODUCTION GIT PUSH

Use two clean extracted copies of this same frontend package.

MAIN WEBSITE REPOSITORY
npm run push:git -- "https://github.com/YOUR_GITHUB_USERNAME/inrishi-main-site.git" main "Deploy Inrishi main production"

PARTNER WEBSITE REPOSITORY
npm run push:git -- "https://github.com/YOUR_GITHUB_USERNAME/inrishi-partner-site.git" main "Deploy Inrishi partner production"

GitHub repository variables:
Main repo:    SITE_DOMAIN = www.inrishi.in
Partner repo: SITE_DOMAIN = partner.inrishi.in

The Apps Script /exec endpoint is already embedded in public/inrishi-config.js.
Do not upload the separate Apps Script backend package to GitHub.
